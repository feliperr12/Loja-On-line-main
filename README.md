# 📚 Sistema de Livraria Virtual

> Projeto desenvolvido para simular uma livraria virtual, permitindo a visualização de livros, adição ao carrinho de compras e cálculo automático do valor total da compra.

## 📖 Sobre o Projeto

Este projeto consiste em uma aplicação desenvolvida utilizando **Vue.js**, com o objetivo de simular o funcionamento básico de uma livraria online.

A aplicação permite que o usuário:

- Visualize uma lista de livros disponíveis.
- Adicione livros ao carrinho de compras.
- Aumente ou diminua a quantidade de cada livro.
- Remova livros do carrinho quando a quantidade chegar a zero.
- Visualize o total de itens selecionados.
- Visualize o valor total da compra em tempo real.

O projeto utiliza conceitos fundamentais do desenvolvimento front-end moderno, como:

- Componentização;
- Comunicação entre componentes;
- Propriedades (Props);
- Eventos personalizados (Emit);
- Computed Properties;
- Manipulação de Arrays;
- Gerenciamento de estado local.
